Python使用

Python 是动态类型的强类型语言，且一切皆对象（全部为引用语义）

    1. 强类型（类型转换严格度维度）

    • 强类型语言不轻易做跨大类的隐式（自动）类型转换，类型不兼容时直接报错，而不是像弱类型的 JS 那样悄悄兜底转换：JS 中 'string' + 1 会把 1 隐式转成 '1' 再拼接，得到 'string1'；Python 中 'string' + 1 直接抛 TypeError，必须显式写 'string' + str(1)。

    • 补充：强弱不绝对，Python 也有明确定义的隐式数值提升（如 1 + 2.0 中 int 提升为 float 得到 3.0），但不会做字符串与数字这种跨界自动转换。

    1. 动态类型
    • Java声明定义变量是将变量和数据锁死在一个盒子里面，声明就定死了类型，但是python盒子里面只有数据，变量只是一张无类型的标签，随意贴随意撕掉,使同一个变量名在不同时刻表现为不同类型。
    • 变量无静态类型声明、类型属于对象，一切皆引用、一切皆对象，变量只是一张无类型的标签，可以贴到任意类型的对象上，类型检查发生在程序运行到该行时，而不是像静态语言那样在变量声明时就把类型定死、编译期检查。
name = '张三'
print(type(name))  # <class 'str'>
name = 1
print(name)   #  1
print(type(name))  # <class 'int'>
print(type(1))  #  <class 'int'>

int()

将其他类型数据转换为十进制整数，支持字符串（需为数字）、浮点数等

# 1. 转换浮点数（截断小数部分）

print(int(5.99))          # 5（不是四舍五入，是截断）

# 2. 转换数字字符串
print(int("123"))         # 123
print(int("-456"))        # -456

# 3. 进制转换（第二个参数指定进制）
print(int("1010", 2))     # 10（二进制转十进制）
print(int("FF", 16))      # 255（十六进制转十进制）
print(int("77", 8))       # 63（八进制转十进制）

# 4. 转换布尔值
print(int(True))          # 1
print(int(False))         # 0

# ⚠️ 注意：不能转换非数字字符串
# int("abc")  # ValueError
# int("12.3") # ValueError（小数点也不行）

enumerate()

返回枚举对象，在循环中同时获取索引和值，常用于 for 循环

# 基本用法
fruits = ['apple', 'banana', 'orange']
for i, fruit in enumerate(fruits):
    print(f"索引{i}: {fruit}")
# 输出：
# 索引0: apple
# 索引1: banana
# 索引2: orange

# 指定起始索引
for i, fruit in enumerate(fruits, start=1):
    print(f"第{i}个: {fruit}")
# 输出：
# 第1个: apple
# 第2个: banana
# 第3个: orange

# 应用于字符串
for i, char in enumerate("Python"):
    print(f"第{i}个字符: {char}")

# 转为列表查看
print(list(enumerate(['a', 'b', 'c'])))  
# [(0, 'a'), (1, 'b'), (2, 'c')]

id()

返回对象的唯一标识符（内存地址），用于判断两个变量是否指向同一对象

# 1. 查看内存地址
a = 10
b = 10
print(id(a))              # 140734567890432（示例地址）
print(id(b))              # 相同的地址（小整数缓存）

# 2. 判断是否同一对象
list1 = [1, 2, 3]
list2 = [1, 2, 3]
list3 = list1

print(id(list1))          # 地址1
print(id(list2))          # 地址2（不同）
print(id(list3))          # 地址1（相同）

print(list1 is list3)     # True（同一对象）
print(list1 is list2)     # False（不同对象，即使内容相同）

# 3. 可变对象的修改
my_list = [1, 2, 3]
prevId = id(my_list)
my_list.append(4)
print(f"修改前后内存地址相同吗？{prevId == id(my_list)}")   # True

进制

用多少个符号，来表示数值的一种『记数方式』。比如我们平时使用的『十进制』，就是用0 ~ 9这十个符号来表示所有的数，而计算机中存储和运算的数据，都是二进制

  • 二进制：0 ~ 1，满2进1。
  • 八进制：0 ~ 7，满8进1。
  • 十进制：0 ~ 9，满10进1。
  • 十六进制：0 ~ 9，A-F，满16进1。

在十六进制中，除了0 ~ 9这十个数字外，还引入了字母，以便表示超过9的值，字母A对应十进制的10，字母B对应十进制的11，同理字母 C、D、E、F 分别对应十进制的：12、13、14、15
