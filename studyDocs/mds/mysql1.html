Mysql

下载并安装Mysql server -- Windows

下载

使用浏览器从下边的地址获得Windows上的MySQL Installer（可以理解为MySQL安装器或者MySQL安装程序）

  1. 看到当前最新版本是v8.0.45
  2. 如果我们想找更早的一些版本的话，可以点击Looking for previous GA versions按钮
  3. 我们看到对于MySQL 8.0.45这个版本的MySQL Installer来说，页面中提供了两个下载按钮，它们的意思分别是：
    • 第一个下载按钮对应的名称是：mysql-installer-web-community-8.0.45.0.msi，这个安装程序比较小，它仅仅包含安装程序和配置文件，并不包含MySQL的主体内容，相当于这只是一个壳，在安装过程中需要连接互联网来下载相应的内容。
    • mysql-installer-community-8.0.45.0.msi：这个安装程序比较大，MySQL的主体内容已经被绑定到该安装程序中，安装过程中不再需要实时下载。
  4. 我们就选择下载这个已经绑定MySQL主体内容的MySQL Installer，点击Download按钮之后进入下边的页面：
  5. 页面提示我们注册或者登录，如果您不想注册或者登录的话，可以直接点击下边的No thanks, just start my download就可以直接将文件下载到自己的计算机上了。我将该文件保存到了D盘下边。

安装

双击下载完成的msi安装包

  1. 出弹窗：The applications requires xxxx, please install the xxxx then run this installer again.
    • 安装运行缺失文件，搜索xxxx并安装
  2. 然后继续运行MySQL Installer，先accept同意协议，点击下一步
  3. choose a Setup Type 选择 Server only，客户端我们自己下载安装Navicat Mysql
  4. 然后点击Next进入Check Reqirements阶段
    • 我们安装的软件可能依赖另外一些软件，当MySQL Installer检测到有一些依赖的软件没有在当前主机安装时，就会进入Check Requirements阶段。从界面中我们可以看到MySQL Server依赖的一个软件没有被安装到本机上，不过Status列的值是空白的，这表明MySQL Installer会自动帮助我们下载并安装这个依赖的软件（如果Status列的值为Manual则需要我们手动的去安装这些依赖的软件）。我们可以点击Execute按钮来让MySQL Installer自动下载并安装依赖的软件。等待下载完成出现了如下界面：
  1. 按照步骤安装依赖文件
  2. 然后继续返回Check Requirements阶段的界面，现在MySQL Server 8.0.45的Status列的值就变为了INSTL DONE，我们就可以点击Next按钮继续安装了：
  1. 之后进入Installation阶段，点击Execute按钮继续安装, 等一会儿就安装完成了
  2. 然后点击Next按钮，进入Product Configuration阶段，在这个阶段可以对我们安装的MySQL Server 8.0.45做一些基本的配置：
  3. 继续点击Next按钮，进入详细的配置界面,安装8.0以上是会多一个Authentication Method的选择，有两个选项，我这里选了传统方式
    • 使用强密码加密授权(推荐)：8.0提供的心的授权方式,采用SHA256基础的密码加密方法.但是需要新版本的connector,目前和Connector/J最新的时8.0目前8.0的连接器和使用libmysqlclient8.0的社区驱动都支持这种新方法.如果客户端和应用程序不能更新来支持这种新授权方法,可以选择使用传统方法.
    • 传统授权方法(保留5.x版本兼容性)
  1. 然后进入了Type and Networking界面，我们仍然保持默认选项，点击Next按钮进入下一步：
  1. 在这个Accounts And Roles界面我们可以为Root用户设置密码，Root用户就是超级管理员，我设置的密码比较简单：123456，大家可以自定义自己的密码哈～ 当然在这个界面中也允许我们再多添加几个用户，不过我们不准备添加了，直接点击Next按钮进入下一步
  1. 这个Windows Service界面是用来将我们安装的MySQL服务器程序设置为一个Windows服务用的，可以在这个界面中设置该Windows服务的名称（界面中显示的Windows服务名默认就是MySQL57，如果我们对服务名称不满意，可以自定义～），以及设置是否在开机时启动MySQL服务器程序。
  1. 其他的部分我们就保持默认设置，继续点击Next按钮：
  1. 我们点击Finish按钮返回到Product Configuration阶段
  2. 从界面中可以看出来，现在已经完成了配置，继续点击Next按钮
  3. 到这里安装过程就结束了，点击Finish按钮退出安装程序。

添加mysql环境变量

上一步如果没有自定义安装目录，那么通常安装在C:\Program Files\MySQL\MySQL Server 8.0\

  • bin目录，这个目录下存放着许多可执行文件,其中有一个mysql.exe，我们通常是将bin下的执行文件都添加到环境变量中
  • 计算器-右键-属性-高级系统设置-环境变量-系统变量，找到变量为Path这一行，双击打开
  • 点击新建，如何把C:\Program Files\MySQL\MySQL Server 8.0\bin\填入。确定-确定-确定
  • 关掉命令行工具（如果之前打开了），执行mysql---报错-环境变量添加成功

mysql命令

进入mysql

mysql -h数据库地址 -u用户名 -p密码

  • mysql -h127.0.0.1 -uroot -p123456
  • 如果是本机，可以省略 -h127.0.0.1
  • 不推荐明文密码连接数据库，推荐 mysql -h127.0.0.1 -uroot -p，然后命令行需要你密文输入密码

退出

  • quit
  • exit
  • \q

mysql执行完成命令需要;结尾

如果你的命令很长，可以通过不添加;换行书写命令，写完后添加 ; 结束书写，执行前面的所有指令
